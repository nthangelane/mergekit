# Research Notes

This directory collects project-specific research notes, experiment writeups,
and utility documentation that used to live at the repository root.

## Contents

- `ga/` - Genetic algorithm implementation notes, run summaries, debugging
  writeups, and adaptive GA TODOs.
- `mac/` - Local Mac/M-series setup, monitoring, and quick-reference notes.
- `assets/` - Images and other small assets used by the research notes.
- `CURRENT_STATUS.md` - Snapshot of current research status.
- `HF_UPLOAD_GUIDE.md` - Hugging Face upload workflow notes.
- `INDEX.md` - Previous research documentation index.
- `todo.md` and `test_todo.md` - Lightweight working notes retained for
  continuity.

The main package documentation remains in `docs/`, and runnable research
helpers now live under `scripts/research/` or `scripts/hf/`.
